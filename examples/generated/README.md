# Generated examples (not yet tested in Cheetah3D)

An agent wrote these scripts using `skill/SKILL.md` while the skill was being evaluated. They pass `tools/c3d_lint.py`, but **none has been run in Cheetah3D yet**. Lines marked `UNVERIFIED` show where the knowledge base had no confirmed answer. They are useful as in-app test cases for the "Verify in app" list in `knowledge/gotchas.md`.

- `Brick Wall.js`: a Polygonobj script. Builds a parametric brick wall with a running bond, seeded jitter and box UVs.
- `Distribute Selected.js`: a Tool script. Spaces a parent's children evenly along X, Y or Z, with undo.
- `Wobble.js`: a Tag script (7.0+). An additive rotation wobble that avoids the read-back trap.
